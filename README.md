## Adding a new PB

1. Save the solves as `records/<event>/YYYY-MM-DD.txt` (paste straight from csTimer — numbered lines with scrambles, or comma-separated times).
2. Run `python3 scripts/build.py`.
3. `git add -A && git commit -m "ao5 PB 12.80" && git push`.

The new record goes to the top of its history and the README updates itself.
