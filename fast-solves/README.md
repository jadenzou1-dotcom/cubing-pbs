## Adding one

Save `fast-solves/YYYY-MM-DD.txt` (`_2`, `_3` for more on the same day):

```
1. 8.42   R2 B2 L2 F D2 ...
> z2 // inspection
> D R' F D' // cross
> U R U' R' // pair 1
> ... // pair 2
> ... // OLL (Sune)
> ... // PLL (T)
# optional note, e.g. full-step, lucky F2L
```

Label steps in `//` comments with the words cross / xcross / pair (or f2l, slot) / OLL / PLL / AUF / inspection, and the step breakdown fills in automatically. Write "skip" in a comment to log a skip.
